ThermoMed Pro – Bluetooth Thermal Receipt Software for Medical Clinics

This web-based application enables healthcare providers to print professional, centered receipts for Random Blood Glucose (RBS) and HbA1c tests directly to any 2‑inch or 3‑inch Bluetooth thermal printer (ESC/POS compatible).

Key Features:

· Fixed Units – RBS value automatically includes "mg/dL", HbA1c includes "%". Only the numeric value is entered, preventing formatting errors.
· Clinic Branding – Upload a logo (PNG/JPG) that prints at the top of every receipt. Logo is saved locally in the browser.
· Centered & Bold Printing – Receipts are printed with center alignment and bold styling for clinic name, RBS, and HbA1c values for clear readability.
· Print History – Every successful print is saved locally. History automatically deletes entries older than 7 days. A three‑dot menu button provides access to view or clear the history.
· Bluetooth Connectivity – Connects to Bluetooth thermal printers using Web Bluetooth (requires Chrome/Edge on HTTPS or localhost). Status indicator shows connection state.
· Live Preview – Real‑time preview of the receipt (including logo and bold formatting) updates as you type.
· Fully Responsive – Modern glassmorphic UI adapts seamlessly to desktop, tablet, and mobile screens.

Ideal for: Clinics, labs, and point‑of‑care testing where quick, reliable, and professional thermal receipts are needed without dedicated driver installation. All data stays on the device – no cloud upload.
